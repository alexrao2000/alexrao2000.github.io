LLM Router

A model router that balances cost and task success on coding workloads.

Measuring the cost of a routing decision

The router uses LiteLLM to work with Claude, GPT, GLM, and DeepSeek from a Python application. Routing lets the system choose among models for different requests instead of using the same model for every coding task.

On SWE-Bench Lite, the measured run cost about 66% less than the Claude Opus 5.5 baseline, with a task success rate within about one percentage point. Together, the two numbers show how much the run saved and how closely it matched the baseline.
