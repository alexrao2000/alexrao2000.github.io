HRI · Voice and Tablet Controls

A team research prototype for configuring a robot by voice, by tablet, or with both.

One robot setting through two interfaces

Our team built two interfaces for a Stretch robot. The voice path used a Flask API to interpret spoken requests and give spoken feedback. The visual path used an Android tablet app built with Kotlin and Jetpack Compose.

The research question was how the interface affects a person’s understanding of the robot. A spoken command lets someone stay focused on the robot, while a visible control can show which setting is being changed. The prototype gave the team a way to explore voice, tablet, and combined interaction.

Changing the volume

In this illustrative Python example, the voice interface interprets a request before it can act. The tablet supplies a value directly. Both paths use the same validation and feedback.

def set_volume(percent):
    if type(percent) is not int or not 0 <= percent <= 100:
        return {"error": "Choose a whole number from 0 to 100."}
    return {"volume": percent, "feedback": f"Volume set to {percent}%."}


def from_voice(transcript, interpret):
    command = interpret(transcript)
    if command.get("action") != "volume":
        return {"error": "I couldn't understand that setting."}
    return set_volume(command.get("percent"))


def from_tablet(slider_value):
    return set_volume(slider_value)
