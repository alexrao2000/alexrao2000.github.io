Soundcheck

A gig tracker for live performers on web and mobile.

Tracking gigs on web and mobile

Soundcheck focuses on keeping track of gigs. A performer might check a gig at a desk or from a phone while out, so the project included both a web app and a mobile app.

The web client uses Next.js and React. The mobile client uses React Native, and Go powers the backend. TypeScript is used in both clients.
