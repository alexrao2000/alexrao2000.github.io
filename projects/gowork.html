gowork

A custom shell and Git tools for everyday development on a team.

Putting shared workflows into the shell

gowork brings shell customization and Git tooling together. The aim is to make common team development tasks easier to repeat when working from a terminal.

It uses Zsh and Bash around Git. The project grew out of two related pieces of work that now share the gowork name.
