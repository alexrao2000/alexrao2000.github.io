Gaming Product Preference

A web product concept exploring physical rewards in a sports betting experience.

Connecting the web experience to an API

The concept paired a sports betting interface with physical rewards. That raised a product question for the web interface. How could a user tell what they might receive in exchange for money?

The technical work included a TypeScript and React frontend backed by an Express API and PostgreSQL. It was a contract project.
