About

A little about me.

I build products and platforms across the stack and work directly with clients. Right now I’m focused on AI agents, orchestration, and evals.

At CurieTech, I’ve been building an open-source agent orchestrator and coding tools for integration developers. I’ve worked directly with clients to build agents and a model router, and set up CI and automated tests. Before that, I helped build C4Y Classroom from the ground up, working on everything from AI chat and voice to authentication and payments.

I like building small tools that help me answer specific questions. Alpha measures how each step in an agent workflow affects quality, cost, and latency. Niche uses DuckDB to run data analysis in the browser and shows the SQL behind each finding.

I studied computer science and economics at Berkeley. Both shape the questions I ask about how things work, who they help, and what would make them worth using.
