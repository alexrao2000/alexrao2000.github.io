Games · Playable prototype

Poem

An original tactical RPG I’m building in Godot. It has a 12-chapter campaign, 24 recruitable characters, and turn-based battles on textured 3D maps.

The interesting part is making all the pieces agree: terrain-aware movement, enemy decisions, combat forecasts, promotions, and character relationships. Campaign saves preserve the random-number state so a battle can resume consistently. It’s still a prototype, with browser and macOS exports.

Visualization · Solo hackathon project

TickerTraffic

A paper-trading game that turns the stock market into a highway. Stocks become lanes, volatility changes their speed, and switching lanes locks in your distance earnings.

I wanted to explore trading decisions through something more familiar than a chart: getting stuck in traffic, changing lanes, and watching the lane you just left speed up. It uses simulated market behavior and was built as a solo hackathon submission.

Research tools · Local-first

Stock Research CLI

A Python command-line tool and browser dashboard for reviewing a portfolio and watchlist against a dated market snapshot.

It reads user-supplied CSVs, calculates portfolio weights, and explains its screening flags with visible rules. Missing inputs stay missing, and the standard analysis runs offline. An optional AI brief adds a second explanation of the supplied data.

Browser extensions · Small useful things

Steam Wishlist Guard

A Chrome extension for a small annoyance: accidentally removing a game from your Steam wishlist and forgetting what it was. It keeps a local removal log and lets you restore entries from the popup.

It catches removal requests as they happen, then compares periodic wishlist snapshots to catch changes made on other devices. Confirmation prompts help prevent mistakes, while duplicate detection keeps the two tracking paths from logging the same removal twice.

Personal tools · Task tracking

Stellar

A daily check-in and task-history app, built to turn recurring tasks into a record I can actually explore.

It imports historical Google Tasks data, syncs recent activity, and presents a calendar, charts, and daily completion records. Date bucketing keeps a task finished after midnight attached to its intended day, while repeat imports update existing records without duplicating them.

Coursework · Computer security

File Sharing System

An end-to-end encrypted file-sharing system I built in Go for Berkeley’s CS 161 computer security course.

The implementation covers account creation, encrypted file storage and appends, sharing between users, and revoking access. It combines symmetric encryption and message authentication with public-key encryption and digital signatures for shared keys.
